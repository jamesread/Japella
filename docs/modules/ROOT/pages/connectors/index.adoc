= Connectors

Connectors connect Japella to chat and social platforms. They send and receive messages and handle authentication for each protocol.

Supported connector guides are listed below and in the sidebar.

== Common prerequisites

Before adding accounts for any OAuth connector:

* Set `base_url` in Japella **Settings** so OAuth callbacks can return to your instance.
* Set `oauth2_redirect_url` to your base URL plus `/oauth2callback`.
* Enable **Is Publicly Accessible** in Settings so OAuth connectors (Mastodon, X, Bluesky, and others) are started.
* Use HTTPS in production (many providers require secure callback URLs).

YAML-configured connectors (Telegram, Discord) are started from `config.yaml` instead; see each guide below.
